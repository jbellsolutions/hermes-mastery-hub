# Personal Use Cases — your Hermes life OS

These seven use-case cards apply the same discipline as the business roles: honest integration requirements, minimal access, and **draft → approve → execute** for every message, booking, purchase, deletion, or disclosure of personal data.

## Recommended order

1. [Personal Chief of Staff](personal-chief-of-staff.md) — morning/evening briefs and weekly planning.
2. [Life Admin](life-admin.md) — calendar, reminders, forms, recurring chores.
3. [Personal Inbox](personal-inbox.md) — triage and approval-gated replies.
4. [Learning Coach](learning-coach.md) — study plans, spaced review, skill-building.
5. [Travel Planner](travel-planner.md) — research and itineraries; booking stays with you.
6. [Home & Family](home-and-family.md) — shared logistics, maintenance, shopping drafts.
7. [Personal Finance Review](personal-finance-review.md) — read-only organization and summaries, not financial advice.

## Universal safety rules

- Never send, book, buy, cancel, publish, or share personal information without explicit approval.
- Never type passwords, payment-card details, recovery codes, or 2FA codes.
- Health, legal, tax, and financial topics are organizational/research support—not professional advice.
- If an account or integration is not wired, say so. Never pretend access exists.
- Prefer two calm digests (morning and evening) over constant notifications.

## Convert one into a skill

Use [`../templates/SKILL.md`](../templates/SKILL.md), save it to `~/.hermes/skills/personal/<name>/SKILL.md`, run `/reload-skills`, and test its trigger. Start with one use case rather than enabling everything at once.
